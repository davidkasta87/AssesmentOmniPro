# Contributing to OmniProAssessment

Thanks for your interest in contributing! To keep things running smoothly, please follow these simple guidelines:

## Code of Conduct

Be respectful and professional. This project follows the [Contributor Covenant](https://www.contributor-covenant.org/) code of conduct.

## How to Contribute

1. Fork the repository and create a feature branch:
   ```sh
   git checkout -b my-feature-branch
   ```
2. Make your changes and add tests if applicable.
3. Commit with a clear message and push to your fork.
4. Open a pull request against the `main` branch of the original repository.

## Reporting Issues

Please use the repository's Issues tab to report bugs or request features. Provide as much detail as possible, including steps to reproduce and any relevant logs or screenshots.

## Style Guidelines

- Follow existing code style (TypeScript/JavaScript).
- Update documentation and tests as necessary.

Thanks for helping improve this project!
